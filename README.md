# Overview

The following jupyter notebooks document my process through *Bartosz Milewski's* **Category Theory For Programmers** [Github](https://github.com/hmemcpy/milewski-ctfp-pdf). 

Each part of the book is subdivided into its own jupyter notebook, containing all that part's chapters.

Each chapter contains:
1. Notes on the chapter, including helpful references/pictures pulled in from other sources to help explain the concepts.
2. Solutions to the chapter problems. The default language used is python. I do not guarantee the veracity of the solutions. 
3. Haskell written solutions to the problems (slow on this because I am prioritizing getting through the book over learning Haskell - hoping it gets in by osmosis)
